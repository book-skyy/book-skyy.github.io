# book-skyy.github.io

Bilingual personal website for internships, research, robotics projects, and academic collaboration.

## Preview

Open `index.html` directly, or serve the repository with any static web server.

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Content

- Chinese and English landing page
- Selected robotics, AI, search, and full-stack projects
- Research interests in embodied intelligence, quadruped navigation, and multimodal foundation models
- Download links for CV and project introduction

## Deployment

This repository is named `book-skyy.github.io`, so GitHub Pages can publish it as:

```text
https://book-skyy.github.io
```

In GitHub, enable Pages from the `main` branch and the repository root.
